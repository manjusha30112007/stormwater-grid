🐬 MySQL Workbench Setup & Verification

SQL scripts included directly in project repository

All database tables and queries can be inspected in MySQL Workbench:

  1. Open MySQL Workbench and connect to Local instance MySQL80 on port 3306.
  2. Check the database mentorconnect in the left-hand Schemas panel.
  3. Run pre-written analytical scripts from the project's mysql-scripts/ folder:
    • 01_schema.sql: Table DDL, Foreign Keys & Indexes
    • 02_sample_data.sql: Sample records & test data
    • 03_queries_and_reports.sql: Real-time queries for tag overlap & engagement reports
USE mentorconnect;
-- View Engagement Report per Mentor Pair
SELECT p.id, a.name AS mentor, s.name AS mentee, 
       COUNT(sess.id) AS total_sessions,
       SUM(sess.status = 'COMPLETED') AS completed
FROM mentorship_pairs p
JOIN alumni a ON p.alumni_id = a.id
JOIN students s ON p.student_id = s.id
LEFT JOIN mentoring_sessions sess ON p.id = sess.mentorship_pair_id
GROUP BY p.id, a.name, s.name;
